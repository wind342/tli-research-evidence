# Archived manuscript navigation

This directory contains historical manuscript-specific evidence maps from earlier versions of the TLI/TLIR research. The **current** manuscript and experiment claims are indexed in the [TLI ICML evidence map](../../TLI_ICML_PAPER_EVIDENCE_MAP.md).

- [Early manuscript evidence map](LEGACY_EVIDENCE_MAP.md)
- [Science-format manuscript evidence map](SCIENCE_EVIDENCE_MAP.md)
- [PNAS-format manuscript evidence map](PNAS_EVIDENCE_MAP.md)

The archived files retain their earlier claims, figure numbers and experimental chronology. Their relative links were adjusted only to preserve navigation after moving the files. For exact previous file bytes, consult the Git commit history.

Original FOCM editorial drafts, renamed TLIR redirect stubs, and redundant Chinese filename aliases were removed from the active tree; their prior contents remain in the repository's commit history. Frozen experimental records, source code, validators and machine results are outside the scope of this archival tidy-up.
